🔄 Live Multi-Device Sync (Firebase)Not connected

Connect every phone / desktop with the same Sync Code. Any change made on one device appears automatically on all other devices (also works after being offline — it merges when back online).

One-time setup (free, ~5 minutes)
  1. Open console.firebase.google.com → Add project (free Spark plan).
  2. Build → Realtime Database → Create Database (any region, start in locked mode).
  3. Build → Authentication → Get started → Sign-in method → Anonymous → Enable.
  4. Realtime Database → Rules tab, paste and Publish:
    { "rules": { "mutton_erp": { ".read": "auth != null", ".write": "auth != null" } } }
  5. Project settings (gear) → Your apps → Web (</>) → register app → copy the firebaseConfig block (must contain databaseURL).
  6. Paste it below, choose a long secret Sync Code, press Connect. Repeat steps 5-6 (same config + same code) on every other device.

Note: all ERP data (including labour Aadhaar numbers) is stored in your own Firebase project. Keep the Sync Code private. Deleted records stay deleted on all devices; records entered on two devices at once are merged, not overwritten.
